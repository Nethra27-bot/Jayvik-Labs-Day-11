Objective

To understand Kali Linux, virtualization, VirtualBox, virtual machine snapshots, and basic Linux commands used in cybersecurity.

Theory – 20 Questions and Answers
1. What is Kali Linux?

Kali Linux is a Debian-based Linux operating system designed for cybersecurity, ethical hacking, penetration testing, and digital forensics.

2. Why is Kali Linux used in cybersecurity?

Kali Linux is used to identify security vulnerabilities, test network security, analyze systems, and perform authorized security assessments.

3. What is a virtual machine?

A virtual machine (VM) is a software-based computer that runs inside a physical computer with its own operating system and virtual hardware.

4. What is a hypervisor?

A hypervisor is software that creates and manages virtual machines and allows multiple operating systems to run on one physical computer.

5. What is VirtualBox?

VirtualBox is free and open-source virtualization software developed by Oracle. It allows users to run different operating systems inside virtual machines.

6. Explain Host OS and Guest OS.
Host OS: The main operating system installed on the physical computer.
Guest OS: The operating system running inside a virtual machine.
7. Why is using Kali inside a VM useful for beginners?

It provides a separate learning environment where beginners can practice cybersecurity without directly affecting their main operating system.

8. What is a VM snapshot?

A VM snapshot is a saved state of a virtual machine that allows users to restore it to an earlier condition.

9. Why should students create snapshots?

Snapshots help students recover their virtual machines if something goes wrong while experimenting or changing system settings.

10. What does whoami display?

It displays the username of the currently logged-in user.

11. What does hostname display?

It displays the name assigned to the computer on the network.

12. What does uname -a display?

It displays complete system information, including the kernel name, hostname, kernel version, and processor architecture.

13. What does /etc/os-release contain?

It contains information about the installed Linux distribution, including its name, version, and identification details.

14. What does ip addr show display?

It displays network interface information, including IP addresses and interface status.

15. What does ip route show display?

It displays the routing table, showing how network traffic is directed to different networks.

16. What is sudo?

sudo stands for Superuser Do. It allows authorized users to execute commands with administrator privileges.

17. Why should elevated privileges be used carefully?

Administrator privileges can modify system files, change settings, delete important data, or damage the operating system.

18. What does sudo apt update do?

It refreshes the package information from configured software repositories to identify available software updates.

19. Why should Kali Linux tools only be used on authorized systems?

Using tools without permission can violate privacy, damage systems, and break cybersecurity laws. Tools should only be used for authorized testing and learning.

20. Explain the difference between ethical security testing and unauthorized access.

Ethical security testing is performed with permission to identify and fix security weaknesses. Unauthorized access involves accessing systems or data without permission and is illegal and unethical.
